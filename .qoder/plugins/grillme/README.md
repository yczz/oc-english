# Grill Me（grillme）

用「连环追问」的方式逼问你的方案或设计，直到设计树的每一个分支都被问清楚。

## 包含的技能

| 技能 | 触发方式 | 作用 |
|---|---|---|
| `grill-me` | 仅用户手动触发（`/grill-me`） | 入口：发起一轮「拷问」 |
| `grilling` | 由 `grill-me` 委托 | 实际工作流：按「轮」提问，每轮问完当前前沿（frontier）的所有问题，每题附推荐答案，等你回答后重算设计树继续下一轮 |

## 工作方式

1. 把你的方案映射成一棵**设计树**：每个决定派生出挂在它下面的后续决定。
2. 分**轮**推进：每轮只问「前置条件已确定」的问题（前沿），全部编号一次性问出，每题给推荐答案。
3. 你回答后，树被重塑——已定的决定解锁下游问题，进入下一轮。
4. **找事实是 AI 的事**（查文件、查工具，不问你）；**做决定是你的事**。
5. 前沿清空 = 设计树全部走完，确认共识后才会动手。
