# 带着OC学英语

养一只属于你的 Q 版 OC，用学英语喂它长大。**两天不学英语，它是真的会饿死的。**

桌面应用 · Tauri 2.0（Rust 后端 + Vanilla JS 前端 + SVG 矢量 Q 版角色）· macOS

## 玩法核心

| 机制 | 规则 |
| --- | --- |
| 🍼 创建 | 免费迎接一只空白小人，去捏脸工坊免费点亮五官/发型/服装；选年龄(8~25)、性格(活泼/文静/傲娇/认真) |
| 📖 学习喂饭 | 四选一答题，答对新词 = 喂食；当日达标 +20 币保底，超额每词 10×难度系数（L1~L5），心情开心档再 +10% |
| 🍞 饥饿 | 当日未完成基础目标，过夜饥饿 -50；饥饿归零 → 饿死 |
| 👻 怨念 | 每饿死一只永久 +30（不可消除）；≥60 时所有 OC 记恨不理你 |
| ⭐ 玩家等级 | 初始满级 5，每饿死 -2 级；等级 0 时助手豆豆拒绝服务 |
| 🕯️ 救赎 | 有饿死的 OC 时可自主发起：连续 7 天全员达标不再饿死 → 全部复活 + 等级 +2；失败可重来，考验翻倍（7→14→28→56） |
| 🤝 互动 | 每天每只 3 次，按性格给出不同反应，维持心情 |
| 🛒 商店 | 用学习赚的币买身份卡、房子等；买食物（80币 +30饱食）救急 |
| 👥 多 OC | 创建免费、不限数量；同一新词当日只能喂一只 |
| 🫧 豆豆 | 小助手，蓝色小球，办事效率高、傲娇，负责播报结算、警告和吐槽 |

跨天自动结算：关窗/几天后再打开，按天数差逐日补算饥饿、心情衰减、饿死与救赎进度。

## 目录结构

```
├── src/                    # 前端（Vanilla JS）
│   ├── index.html          # 游戏主界面
│   ├── main.js             # 游戏逻辑（答题/商店/捏脸/救赎）
│   ├── styles.css          # 深色主题
│   └── pixel/              # 矢量 Q 版角色渲染器（手绘软萌风）
│       ├── render.js       #   部件 path + 调色板 → SVG，任意缩放不糊
│       └── styles.js       #   部件数据（素体/五官/发型/服装）+ 调色板
├── src-tauri/              # Rust 后端
│   ├── src/
│   │   ├── models.rs       #   存档数据结构
│   │   ├── settle.rs       #   跨天结算（饥饿/心情/怨念/饿死/救赎）
│   │   ├── words.rs        #   题库加载 + 四选一题目生成
│   │   └── commands.rs     #   Tauri 指令（全部游戏规则落点）
│   └── data/               # 五级题库 words_L1~L5.json（各 100 词，已编译进二进制）
└── docs/DESIGN.md          # 设计稿 v6.1（19 章，全部机制定稿）
```

存档位置：`~/Library/Application Support/com.zhengzhong.oc-english/player.json`

## 开发

```bash
# 环境：Rust (rustup) + Node.js 22；npm 已配国内镜像
npm run tauri dev     # 开发模式热运行
```

## 打包

```bash
npm run tauri build
# 产物：src-tauri/target/release/bundle/macos/带着OC学英语.app
#       src-tauri/target/release/bundle/dmg/带着OC学英语_0.1.0_aarch64.dmg
```

未做签名公证的包，若首次打开被 Gatekeeper 拦截：右键 → 打开，或执行
`xattr -cr 带着OC学英语.app`。
