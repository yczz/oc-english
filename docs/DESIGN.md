# 带着OC学英语 · 设计稿 v6.1

> 一款 Tauri 2.0 桌面应用：把你的 OC 当成自己的孩子养在小屋里。**两天不学英语，孩子就会饿死**——学习是喂养，超额学习挣「钱」。每只 OC 有独立心情（性格不同反应不同，倔强的饿了都不求救，全靠傲娇小助手豆豆提醒你）。饿死孩子会累积**永远无法消除**的怨念值、扣除你的玩家等级；等级归零连豆豆都不理你。好友可以带 OC 串门，还能把自家 OC 的经历发上分享网，豆豆每月评选「最佳家长」排行榜。

---

## 1. 核心循环（v6）

```
捏一个Q版空白小人(免费) ──→ 住进素白小屋(只有床) ──→ 每天完成基础学习 = 喂饱 OC
     ↑                                                  ↓
  挣"钱" ←────── 超额学习 × 难度系数 ←───────────────────┘
     ↓
花"钱"：身份卡(→豆豆生成世界观) / 家具 / 装备 / 心情玩具 / 新OC槽位
     ↓
养更多 OC → 学更多英语
饿死孩子 → 怨念↑(永久) + 等级-2 → 等级0：不能串门、豆豆拒绝服务
饿死并非绝路：你可以亲自发起救赎，成功了孩子们都会回来（见 §5.2）
```

四重情感压力：饿死 · 心情低落 · 怨念（永久账本）· 等级（社会性死亡）。

## 2. 饥饿与生存系统

| 状态 | 饥饿值 | 表现 |
|------|--------|------|
| 饱腹 | 76~100 | 笑脸，台词轻松 |
| 正常 | 51~75 | 平静 |
| 饥饿 | 26~50 | 台词抱怨饿（因性格而异，见 §3.3） |
| 危险 | 1~25 | 求救（倔强性格不表现求救，仅豆豆警告） |
| 饿死 | 0 | 死亡：头像灰化、小屋定格、怨念 +30、**玩家等级 -2**；可被救赎召回（§5.2） |

```
初始饥饿值 = 100
每日结算：当日完成基础学习 → 回满 100；未完成 → -50（2 天饿死）
```

- 喂食只认**当日新学会的词**（错题重做不喂食）
- 应急食物 80 币 +30 饥饿（饥饿/危险状态可用）

## 3. 心情与健康系统（性格差异化）

### 3.1 心情值 0~100（每 OC 独立，不致死）

开心 76~100（性格专属欢快动画 + 结算币 +10%）/ 平常 26~75 / 低落 1~25（灰暗抱膝、答题不围观）/ 沉郁 0（躺床，台词只剩省略号）。

### 3.2 性格心情系数表

| 事件 | 活泼 | 文静 | 傲娇 | 认真 |
|------|------|------|------|------|
| 被喂饱 | +20 蹦跳 | +12 微笑 | +15（嘴硬） | +10 点头 |
| 答对 1 题 | +5 拍手 | +3 | +2 别过头 | +8 记笔记 |
| 答错 | -2 摆手 | -1 | -5 跺脚 | -2 扶额 |
| 新家具 | +15 欢呼 | +8（书类 +15） | +6 | +5 检查 |
| 新装备 | +12 展示 | +6 | +10（脸红） | +4 |
| 打招呼 | +8 扑过来 | +5 挥手 | +3 抱臂 | +2 鞠躬 |
| 饥饿过夜 | -10 | -8 | -12 闹脾气 | -5 |
| 闲置 1 天 | -8 | -4 | -6 | -3 |

心情玩具（各 60 币，投性格所好 +20 / 其他 +8）：皮球→活泼、绘本→文静、小镜子→傲娇、计划本→认真。打招呼免费但每日限 3 次计心情。

### 3.3 求助阈值差异化（倔强的孩子不求救）

| 性格 | 饥饿状态 | 危险状态 |
|------|---------|---------|
| 活泼 | 「肚子咕咕叫了！」（明显） | 「求求你别走…」（强烈求救） |
| 文静 | 「有点饿了…」（轻微） | 「还差一点点…」（微弱） |
| **傲娇/倔强** | 「哼，不用你管。」（完全掩盖） | 「…才不需要谁。」（不求助） |
| 认真 | 「饥饿值低于 50，请注意。」 | 冷静报数 |

豆豆是无条件兜底（饥饿 <25 必警告）——**但等级 0 时豆豆拒绝服务**（§5），倔强孩子的命就真没人管了。

### 3.4 动作库

每性格一套 idle 帧动画，按心情档位切换动画集。

## 4. 怨念值系统（永久不可消除）

> 你无法替被你饿死的 OC 消除他们的怨念。

- 全局 **0~100**，紫色怨念图标常显，永久记录
- **每饿死一只 +30，任何行为无法减少**
- 分层效果：0~29 无事 / 30~59 冷淡期（心情每日额外 -5、台词变冷）/ 60~100 **记恨期**（不说话、不理你、不接受玩具、心情加成失效）
- 立碑（100 币）= 安葬纪念 + 释放槽位，**不消怨念**
- 唯一例外：§5.2 救赎成功后，**记录保留但效果解除**（孩子们选择回来，本身就是原谅）

## 5. 玩家等级与救赎机制（v6 新增，v6.1 修订）

### 5.1 玩家等级

```
初始等级 = 5（满级，因为你没饿死过任何一个孩子）
每饿死一只 OC：等级 -2（只减不增，永久账本，与怨念同理）
```

| 等级 | 解锁 |
|------|------|
| 5 | 满级家长：串门、分享网全功能、豆豆全情服务 |
| 3~4 | 串门正常，豆豆服务时偶尔阴阳怪气 |
| 1~2 | 可串门，豆豆话变少 |
| **0** | **社交性死亡：不能串门，豆豆拒绝服务** |

等级 0 时豆豆的原话：「我不想和饿死孩子的人说话。」——倔强 OC 的唯一警报也随之消失，你只能靠自己去记每一只孩子的饥饿条。

### 5.2 救赎机制（v6.1 修订·玩家自主发起）

> 有人会因为急事、太忙，无法照顾孩子——系统无法替他的 OC 决定生死，**但玩家自己可以**。想让孩子回来，就亲自去赎。

- **发起**：只要存在饿死的 OC，玩家**随时可自主发起「救赎」**（从灰头像或墓碑入口发起，不依赖豆豆，等级 0 也能发起）
- **考验期**：发起后进入 **7 天考验期**，期间每天必须：
  - 完成全部**存活** OC 的基础学习（一只不落）
  - 不再饿死任何 OC
- **救赎成功**：**所有饿死的 OC 全部复活，回来**——孩子们回归各自小屋：
  - 复活的 OC 初始心情 40（低落档）：人回来了，但还需要你重新哄
  - 玩家等级 +2（上限 5），记恨效果解除
  - 怨念账本记录保留（历史不改），但孩子们选择回来本身就是原谅
- **救赎失败**（考验期内断签或再饿死）：考验终止，可**再次发起**，但下次考验期翻倍（7→14→28 天…）——门永远开着，但越走越贵
- 复活的 OC 与普通 OC 完全一致：可继续被喂养、被换装、参与串门与排行榜

## 6. 角色创建（从空白小人开始）

### 6.1 Q 版空白小人流程（全程免费）

```
第1步  一个什么都没有的小小人（无发型、无五官、无衣服的Q版素体，圆润可爱站姿）
第2步  ➕眼睛（6款 × 瞳色6色）……小人眨眼了
第3步  ➕嘴巴（5款）……会笑了
第4步  ➕发型（8款 × 发色8色，或去发型工坊让豆豆现场做一个）
第5步  ➕初始服装（3套免费：校服/连衣裙/运动装）
第6步  名字 / 年龄 8~25 / 性格 4 选 1（不选世界观，见 §7）
──→ 入住「素白小屋」：只有一张床的中性风格房间
```

### 6.2 发型工坊（豆豆现场做发型）

- 入口：发型选项框底部「➕ 让豆豆做个发型」
- **参数合成器**：长度（短/中/长）× 刘海（齐/斜/中分/无）× 两侧（垂发/单马尾/双马尾/双丸子/编发）× 蓬松度 × 发色 → 实时预览合成到小人头上
- 满意 → 命名保存 → **加入你的发型选项框**（存档私有、免费、数量不限）
- ⚠️ 等级 0 时豆豆不接单（§5）

## 7. 身份卡与世界观（豆豆生成）

### 7.1 流程

```
商店买身份卡（首张 200 币起递增）→ 你把想要的世界告诉豆豆
（自由描述：时代/身份/生平，或「我想要一个赛博朋克的世界」）
→ 豆豆生成这个世界 → 你的 OC 就活在这样的世界里
→ 豆豆会推荐同风格的房子，但你可以换成其他风格
```

### 7.2 生成逻辑

- **首期（离线规则引擎）**：描述命中预置主题关键词 → 套用（现代⭐/古风🪙/西幻💰）；未命中 → 豆豆引导填「自定义世界观表」（世界名/货币名/主题色/称谓）→ 生成专属世界，完全离线
- **二期（可选）**：接 LLM 自由生成

### 7.3 房子风格：推荐但可换

- 生成时豆豆按世界风格推荐建筑皮肤与家具，**不强制**
- 建筑与家具皮肤可在装扮页自由更换（换皮仅外观，功能价格不变）
- 世界观本体（货币名/称谓/台词点缀）绑定 OC 不可改

## 8. 小助手「豆豆」

### 8.1 形象与性格

蓝色圆球 + 两颗豆豆眼，悬浮右下角，有事件时眼睛变「!」。**性格：办事效率快、傲娇**——回复短平快、命令式、嘴硬心软。

### 8.2 职能

| 职能 | 说明 |
|------|------|
| 新手引导 | 首次进入各页面一句点拨 |
| 状态播报 | 无条件播报所有 OC 饥饿/心情/怨念（等级 0 时停服） |
| 规则问答 | 关键词匹配 |
| 生成世界观 / 发型 | §6 §7 |
| 月度养育评分 | §9.3 排行榜评估 |
| 敲打你 | 怨念 ≥60：「孩子们都在看着你呢。自己做的事，自己收拾。」 |

### 8.3 输入方式

1. 快捷短语大按钮（「孩子们怎么样？」「怎么挣铜钱？」「做个发型」）——零门槛
2. 打字输入
3. 语音输入（二期 M8，whisper-rs 本地离线转录）

## 9. 社交系统（v6 新增·二期联网功能）

> 单机闭环（M1~M8）先行，社交（M9~M10）在单机版稳定后上线，需要账号与服务端。

### 9.1 分享网

- **登录**后可用：注册/登录分享网账号（昵称 + 头像可用自家 OC 像素头像）
- **发布**：把自家 OC 的**经历**发上分享网——OC 像素立绘快照 + 小屋截图 + 文字故事（可让豆豆代笔：从存档数据自动生成「养育周报」，如「本周喂饱 7 天，学会了 43 个词，买了第一张书桌」）
- **互动**：评论、点赞、加好友（好友申请双向确认）

### 9.2 好友串门

- 前提：**玩家等级 ≥1**（等级 0 不能串门）
- 好友的 OC 来访你家小屋：来访 OC 像素形象出现在你的房间里，两家 OC 有一组互动台词（按双方性格组合生成，如 傲娇×活泼 =「你、你谁啊！」「哇！新朋友！」）
- 串门后双方 OC 心情 +10（每日限 1 次访客）
- 来访记录可回访（点「回串门」跳转好友列表）

### 9.3 月度养育榜（豆豆评估）

每月 1 日，豆豆结算上月数据，评选全体玩家「**最佳家长**」：

```
养育评分 = 喂食全勤率 ×40 + 平均心情 ×30 + 互动频率 ×15 + 零怨念加成 ×15
（上月有饿死记录者直接失去高分档资格）
```

- 第一名获当月「最佳家长」称号徽章（分享网主页展示）
- 榜单展示前 100 名 + 你的排名
- 评分与榜单全部由豆豆（服务端）计算，玩家端只读

### 9.4 隐私边界

分享/串门仅公开：OC 形象、小屋外观、养育周报数据；不公开个人学习明细与错题内容。

## 10. 货币系统

- 完成每日基础学习 → 保底 20 币；超额 → `超额词数 × 10 × 难度系数`（L1~L5 = 1.0/1.2/1.5/2.0/2.5）
- 心情「开心」档 +10%；当日同词去重
- 货币名/图标随当前 OC 世界观（现代⭐/古风🪙/西幻💰/自定义）

## 11. 多 OC 系统

- 头像栏 `[😀][😀][😵灰][＋]` + 怨念图标 + **等级徽章**；选中 = 当前喂食对象
- 槽位：**当前不设限制，创建全部免费**（用户 2026-08-23 决定；原方案：免费 / 500 / 1500 / 4000 币，后续可调回收费）
- 每只 OC 独立每日目标；**同一新词当日只能喂一只**（全局去重）→ 养 N 只 = N 倍学习量

## 12. 难度分级与题库

五级（L1 小学/L2 初中/L3 高中/L4 四级/L5 六级）首期各 100 词，题库存 `{word, pos, meaning}`，四选一干扰项答题时同级动态抽取。题型：看词选义；错题本重做不喂食（书架加成 +2 币/词）。

## 13. 小屋与商店

家具 14 件（台灯 50 / 书桌 150 解锁错题本 / 书架 200 / 收音机 300 首题双倍 / 小猫 500 登录+10 / 电脑 800 / 钢琴 1000 / 双人床 1500…）、装备 15 件、身份卡 200 起、应急食物 80、心情玩具 ×4 各 60、墓碑 100（OC 槽位当前免费不限）。家具皮肤随世界观推荐但可自由更换。

## 14. 学习模块

- 每 OC 单独设每日目标（1~50 词）；难度全局
- 答题页：当前喂食对象头像 + `3/2 ✓已喂饱` + 心情表情
- 跨天结算（Rust 侧）：所有 OC 饥饿判定 + 心情衰减 + 怨念效果（只增不减）+ 救赎考验进度判定
